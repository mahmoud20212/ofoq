# كود الطالب وسجل التحقق

واجهة الحل والحفظ والتشغيل الجديدة: [LAB_SOLVE_UI.md](LAB_SOLVE_UI.md).

قائمة التحديات العامة وحالاتها المجمعة دون واجهة حل: [LAB_DISCOVERY.md](LAB_DISCOVERY.md).

خدمات خلفية فقط، دون محرّر أو اتصال Judge0 أو تغيير نتائج التقييم. تستخدم
`StudentChallengeCode` وقيوده القائمة؛ لا ترحيل جديد. الإتاحة مغلقة افتراضيًا
بـ`LAB_EDITOR_API_ENABLED=False` وتُفتح في إعدادات المعاينة فقط. السجل ولقطة المحاولة
يتبعان `LAB_SUBMISSION_API_ENABLED` الحالي.

## قراءة المسودة

`GET /lab/challenges/<challenge_id>/versions/<version_id>/code/`

جلسة طالب نشطة؛ نسخة منشورة معتمدة متاحة وفق `challenge_for_execution` الحالي،
بما فيه الالتحاق وصلاحية اللغة والفحص المرجعي. لا يكفي إرسال رقم نسخة عمل.

```json
{
  "version_id": 1,
  "version_uid": "UUID",
  "code": "# starter\n",
  "saved": false,
  "revision": 0,
  "saved_at": null,
  "editable": true,
  "learning_status": "not_started",
  "language": {"name": "Python", "version": "3.8.1"}
}
```

غياب السجل يعيد كود البداية ولا ينشئ سجلًا. بعد الحفظ يصبح `saved=true` ورقم
المراجعة 1 ثم يزيد مع كل حفظ مقبول، ويظهر وقت الحفظ الفعلي. الكود الفارغ المحفوظ
يبقى فارغًا؛ لا يُستبدل بكود البداية. تُحفظ الأسطر والمسافات وCRLF كما أرسلها الطالب.

## تحديث المسودة والتعارض

`POST /lab/challenges/<challenge_id>/versions/<version_id>/code/save/`

`Content-Type: application/json` مع جلسة وCSRF cookie وترويسة `X-CSRFToken`.
الحقول المقبولة فقط:

```json
{"code": "print('مرحبا')\n", "revision": 0}
```

النجاح 200 يعيد نفس عقد القراءة، بالكود المحفوظ ورقم المراجعة الجديد. رقم المراجعة
عدد صحيح إلزامي وليس boolean؛ صفر يعني أن الطالب قرأ نسخة بلا مسودة. الحد 100000
محرف و400000 بايت UTF-8، أو سقف المصدر الأصغر في إعداد الموصل. يُسمح بسلسلة فارغة.
لا تؤخذ اللغة أو الطالب أو حدود التنفيذ من المتصفح. لا اتصال بالخدمة ولا استهلاك
لحصة تشغيل ولا تسجيل نجاح عند حفظ المسودة.

الحفظ يأخذ قفل الدورة/التحدي المستخدم في النشر، ويعيد التحقق من الإتاحة داخله.
يقارن رقم المراجعة داخل المعاملة؛ التحديث مشروط بالرقم نفسه (CAS)، والإنشاء محمي
بالقيد الفريد القائم. حجز كتابة SQLite وإعادة محاولات قفل قاعدة البيانات الحالية
يحميان الإنشاء المتزامن أيضًا؛ لا تعاد أي عملية شبكة.

التعارض 409:

```json
{"error":{"code":"code_revision_conflict","message":"حُفظ تعديل أحدث من نافذة أخرى؛ احتفظ بكودك واقرأ النسخة الأخيرة قبل الدمج"}}
```

**عقد المحرر اللاحق:** احتفظ بالكود المحلي غير المحفوظ، واقرأ أحدث نسخة عبر GET في
ذاكرة منفصلة. اعرض اختيار الدمج أو اعتماد النسخة الجديدة للمستخدم. لا تستبدل الكود
المحلي أو تعاود الحفظ تلقائيًا برقم مراجعة أحدث. بعد قرار صريح أرسل النص المختار مع
أحدث رقم. ضياع رد الحفظ قد يؤدي إلى 409 عند إعادة الطلب؛ القراءة والمقارنة تحسمان
ما حُفظ، دون ادعاء نجاح قبل تأكيد الخادم. لا merge تلقائي ولا last-write-wins.

## نسخة جديدة والأرشفة

- عنوان المسار يثبّت النسخة، فلا يحفظ تبويب قديم على النسخة الجديدة دون قصد.
- النسخة المنشورة الجديدة تبدأ بكود بدايتها ورقم صفر عند غياب مسودتها. لا نسخ
  تلقائي لمسودة قديمة ولا توريث نجاحها.
- مسودة نسخة معتمدة سابقة محفوظة لهذا الطالب قابلة للقراءة فقط (`editable=false`).
  لا تُفتح نسخة سابقة بلا مسودة خاصة للطالب، ولا تُفتح مسودة معلّم.
- أرشفة التحدي تمنع الحفظ الجديد؛ تبقى المسودة المحفوظة والسجل قابلين للقراءة وفق
  سياسة السجل الحالية. حذف مصدر النسخة لا يمحو صف الكود (`SET_NULL` القائم)، لكن
  هذا المسار لا يعيد بناء هوية المصدر المحذوفة؛ يبقى الصف للإدارة.
- الدورة المؤرشفة تبقى للملتحق. إلغاء التحاقه يمنع قراءة المسودات والسجل واللقطات
  والنتائج عند كل طلب. لا كشف لهوية طالب آخر ولا قبول `student_id` من المتصفح.

## السجل واللقطة

`GET /lab/challenges/<challenge_id>/submission-history/?page=1`

20 عنصرًا لكل صفحة، الأحدث حسب `created_at DESC, pk DESC` لكسر تعادل الوقت.
`page` موجب؛ غير الصالح 400، والصفحة خارج النطاق 404. الصفحة الأولى الفارغة 200.

```json
{
  "results": [{
    "submission_id": 1, "version_uid": "UUID", "status": "finished",
    "phase": "complete", "verdict": "accepted", "passed": true, "solved": true,
    "created_at": "ISO-8601", "finished_at": "ISO-8601",
    "total_cases": 2, "evaluated_cases": 2,
    "hidden_summary": {"total":1,"evaluated":1,"passed":1,"not_passed":0},
    "result_url": "/lab/submissions/1/", "code_url": "/lab/submissions/1/code/"
  }],
  "page":1, "page_size":20, "count":1, "pages":1, "has_next":false,
  "learning_status":"solved"
}
```

نسخة المحاولة محددة بـ`version_uid` الثابت، حتى لو حُذف المصدر. السجل يشمل نسخ
التحدي السابقة ولا يعيد تفسيرها بالمنشور الجديد. يستخدم مسلسِل النتيجة الحالي
بوضع الملخص مع تحميل نتائج الصفحة وإنجازاتها على دفعات؛ لا استعلام لكل حالة اختبار.

`GET /lab/submissions/<submission_id>/code/` يعيد لصاحبها فقط:
`submission_id`, `version_uid`, `code`, `created_at`, و`language` باسمها وإصدارها.
هذه لقطة الكود الأصلية غير القابلة للتعديل، وليست مسودة المحرر الحالية.

`result_url` يعيد عقد النتيجة الموجود في [LAB_SUBMISSIONS.md](LAB_SUBMISSIONS.md):
تفاصيل الحالات الظاهرة فقط، وأعداد للمخفية. لا تنقل لقطات التقييم أو private_result
أو الحل المرجعي أو معرّفات/مدخلات/مخرجات/أخطاء الحالات المخفية إلى استجابة الطالب.
لا بيانات مخفية في سجل الملخص أو استجابة الكود. كل الردود خاصة وغير قابلة للتخزين
المشترك؛ تُعرض الأكواد والمخرجات لاحقًا كنص وليس HTML.

## حالة الطالب

الحالة خاصة بالطالب وUUID النسخة:

- `not_started` / لم يبدأ: لا مسودة ولا تشغيل ولا تحقق ولا إنجاز.
- `in_progress` / قيد الحل: يوجد حفظ كود (حتى الفارغ)، أو تشغيل أو محاولة تحقق، دون إنجاز.
- `solved` / تم الحل: يوجد `ChallengeSuccess` لنفس النسخة. محاولة فاشلة لاحقة لا تمحوه.

حالة السجل العليا تخص النسخة المنشورة الحالية، و`solved` في صف المحاولة يخص نسختها.
القراءة وحدها لا تبدأ العمل. لا تغيير لتقدم المحتوى أو الاستئناف أو استحقاق شهادة.

## التحقق

`courses.tests_lab_editor` مع `courses.tests_lab_submissions` و`courses.tests_lab_runs`.
قاعدة SQLite وملفات مؤقتة معزولة، وخدمة Judge0 محاكاة فقط. اختبارات نافذتين تشمل
الحفظ الأول وتحديث سجل قائم. لا ادعاء باختبار PostgreSQL أو حمل إنتاج، ولا تشغيل
حقيقي جديد على AWS في هذه المهمة لأن الحفظ والسجل لا ينفذان كودًا.

نتيجة تشغيل 2026-11-19: **80 اختبارًا ناجحًا، صفر فشل وصفر تخطٍّ**: 24 للمحرر
والسجل، و28 للتحقق، و28 للتشغيل. اختبار صفحة 20 محاولة يتحقق من سقف 9 استعلامات
للسجل بالكامل. فحص Django سليم، و`makemigrations courses students --check --dry-run`
لا يقترح ترحيلات. بصمة `educa/db.sqlite3` متطابقة قبل الاختبارات وبعدها.
