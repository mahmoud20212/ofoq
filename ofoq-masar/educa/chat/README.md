# دردشة دورات مَسار

الغرفة متاحة للطالب الملتحق ومعلّم الدورة فقط. تعتمد على جلسة Django الحالية، بما فيها جلسة الدخول المرتبطة بـKeycloak. لا تُرسل رموز الهوية إلى الواجهة أو إلى رابط WebSocket.

## التشغيل المحلي

- عنوان مَسار المعتمد: `http://localhost:8000`.
- شغّل Redis الموجود، ثم خادم Django/Daphne المعتاد. تطبيق `daphne` مسجّل بالفعل في إعدادات المشروع.
- `REDIS_URL` اختياري، وافتراضيًا `redis://127.0.0.1:6379/0`. يُستخدم للاتصال بين العمليات وتحديد معدل الإرسال.
- `CHAT_ALLOWED_ORIGINS` قائمة مصادر مفصولة بفواصل، وافتراضيًا قيمة `MASAR_AUTH_URL`. عند النشر يجب أن تطابق عنوان المنصة مع HTTPS. الواجهة تختار `wss` تلقائيًا.
- تطبيق الترحيل: `python manage.py migrate chat`. الترحيل إضافي ويحافظ على الرسائل القديمة.

## السلوك

- آخر 50 رسالة عند فتح الغرفة، مع تحميل الرسائل الأقدم واستعادة الرسائل الفائتة بعد إعادة الاتصال.
- نصوص فقط، من حرف واحد إلى 2000 حرف، وبحد عشر رسائل خلال نافذة عشر ثوانٍ لكل مستخدم ودورة.
- طلب الإرسال يحمل UUID، ويمنع قيد قاعدة البيانات حفظ الطلب نفسه مرتين. إعادة المحاولة تستخدم UUID نفسه، والواجهة تزيل تكرار الرسائل بمعرّف قاعدة البيانات.
- الخادم يحفظ قبل البث. يعاد التحقق من جلسة الخادم والصلاحية عند الإرسال والتسليم وكل 30 ثانية أثناء الخمول.
- انتهاء الجلسة أو إبطالها مركزيًا يوقف الاتصال. لا يحدّث WebSocket رموز Keycloak؛ تجديد الدخول يبقى في تدفق HTTP الموجود.
- لا إشعارات خارج الغرفة أو مرفقات أو ردود متفرعة أو تعديل وحذف للرسائل.

## التحقق

```powershell
python manage.py test chat.tests_room
node --test chat/tests_client.cjs
$env:CHAT_RUN_REDIS_TESTS='1'
python manage.py test chat.tests_redis
```

اختبار Redis يستخدم قاعدة Django المعزولة ومفاتيح مؤقتة ذات بادئة عشوائية؛ لا يمسح مفاتيح الخدمات الأخرى.
